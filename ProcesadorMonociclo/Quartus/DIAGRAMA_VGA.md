│       - Calcular col_index = x / 64                                             │
│       - mem_addr = row_index * 16 + col_index                                   │
│       - Leer mem_data = data_memory[mem_addr]                                   │
│                                                                                  │
│  3. Generador de caracteres:                                                    │
│     - Extraer nibble: hex_digit = mem_data[31:28 ... 3:0]                      │
│     - Buscar bitmap en font_rom[hex_digit][char_y]                              │
│     - Obtener pixel = font_line[char_x]                                         │
│                                                                                  │
│  4. Salida de color:                                                            │
│     - Si pixel = 1 → VGA_RGB = COLOR_TEXT                                       │
│     - Si pixel = 0 → VGA_RGB = COLOR_BG                                         │
│                                                                                  │

## Especificaciones Técnicas

### Resolución VGA: 1280×800 @ 60Hz

| Parámetro          | Pixels/Lines | Tiempo      |
|--------------------|--------------|-------------|
| Visible H          | 1280         | 15.33 μs    |
| Front Porch H      | 48           | 0.58 μs     |
| Sync Pulse H       | 32           | 0.38 μs     |
| Back Porch H       | 80           | 0.96 μs     |
| **Total H**        | **1440**     | **17.25 μs**|
| Visible V          | 800          | 13.80 ms    |
| Front Porch V      | 3            | 0.05 ms     |
| Sync Pulse V       | 6            | 0.10 ms     |
| Back Porch V       | 22           | 0.38 ms     |
| **Total V**        | **831**      | **14.33 ms**|
| **Pixel Clock**    | -            | **83.46 MHz**|
| **Refresh Rate**   | -            | **~60 Hz**  |

### Recursos FPGA Estimados

| Componente                 | Logic Elements | Memory Bits | PLLs |
|----------------------------|----------------|-------------|------|
| Procesador RISC-V          | ~150           | 131,072     | 0    |
| Memoria Datos (dual port)  | ~50            | 32,768      | 0    |
| VGA Controller             | ~100           | 0           | 1    |
| VGA Memory Display         | ~2000          | 4,096       | 0    |
| Font ROM                   | ~100           | 2,048       | 0    |
| **TOTAL**                  | **~2500**      | **169,984** | **1**|
